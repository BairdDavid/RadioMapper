About the Radio Coverage Viewer

This tool is designed to visualize radio signal strength (RSSI) data from a CSV file on an interactive map. It allows you to see the geographic coverage and quality of a radio network based on collected data points.

CSV File Format Guide

For the application to work correctly, your CSV file must follow a specific structure composed of three parts: a file header, a column header, and the data rows.

1. File Header (Lines beginning with #)

This section provides metadata. The application looks for the following optional values:

  • # Model: [value] - Displayed in the "Info" section. Shows "unknown" if not present.
  • # Receiver ID: [value] - Displayed in the "Info" section. Shows "unknown" if not present.
  • # Description: [value] - Displayed in the "Info" section. Shows "unknown" if not present.
  • # Max good RSSI: [value] - Sets the "Good" signal threshold for coloring the map points. Defaults to -90 if not present.
  • # Max okay RSSI: [value] - Sets the "Weak" signal threshold for coloring the map points. Defaults to -114 if not present.

Any other header lines (e.g., for PDOP, HorErr) are ignored.

2. Column Header Line

This single line defines the data in the columns that follow. The application requires the following column names:

  • Date
  • Time
  • Lat (Latitude)
  • Lon (Longitude)
  • RSSI

Any other columns in your file will be ignored.

3. Data Rows

These rows contain the measurement data corresponding to the column header.

  • Time Format: The Date and Time are read directly from the file. No timezone adjustments are made, so the data should ideally be in **UTC**. The expected date format is MM/DD/YYYY.
  • Coordinate (Lat/Lon) Format: The advised format is **Decimal Degrees** (e.g., 39.895367). The application will also automatically convert from other common GPS formats like Degrees Minutes Seconds (e.g., 39.53.4332630).

Interpreting the Map

The map displays your data as a series of colored dots. The color of each dot corresponds to its RSSI value, providing a quick visual reference for signal quality.

  • Green: Strong signal (at or above the "Good" limit).
  • Yellow/Orange: Moderate signal.
  • Red: Weak signal (at or below the "Weak" limit).

Click on any individual dot on the map to open a popup with its exact Date, Time, and RSSI information. You can switch between a street map and satellite imagery using the layer control in the top-right corner of the map.

Using the Filters

The "Filters" section allows you to explore your dataset.

  • Time Filter: Filters the data points to a specific time range. The times you select are interpreted as UTC.
  • RSSI Limit (Good/Weak) Slider: This slider controls the **color grading** of the dots on the map. Its initial position is set by the # Max good RSSI and # Max okay RSSI values from your file's header (or defaults to -90 and -114 if they are not provided).
  • RSSI Range (Min/Max) Slider: This slider **hides data points** from the map. Its initial range is set to the best and worst RSSI values found in the entire dataset. Adjusting the handles will cause points with an RSSI outside the selected range to disappear.

Click Apply Filters to update the map after making changes. Click Reset Filter to return all filters to their original state.
